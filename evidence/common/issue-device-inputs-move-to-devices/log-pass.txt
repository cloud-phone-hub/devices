# 输入目录迁移 #238 —— 迁移后验证记录（2026-11-15）

## 1. 目录迁移

```
$ mv engine/hardware devices/hardware
$ mv engine/kernels  devices/kernels
$ mv engine/manifest devices/manifest
$ mv engine/modules  devices/modules

$ ls engine
out  roms
$ ls devices
evidence  hardware  kernels  manifest  modules

$ du -sh devices/hardware devices/kernels devices/manifest devices/modules
522M	devices/hardware
 17G	devices/kernels
1.3M	devices/manifest
 16M	devices/modules
```

## 2. 根定位与访问器

- `engine.Init()` 改为识别 `<仓库根>/engine` + `<仓库根>/devices/manifest`；
- 新增 `engine.WorkspaceRoot/DevicesRoot/ManifestRoot/HardwareDir/KernelsRoot/ModulesRoot/EvidenceRoot`；
- `profile.findRoot` / `HardwareDir` 改判 `devices/hardware`；
- agent 侧新增 `tools.DevicesRoot/ManifestRoot`，manifest.show、上下文包、
  `/api/manifest/*`、`/api/runs/{id}/evidence`、`CDH_DEVICES_DB` 全部改用；
- cdha read/write roots 增加 `<仓库根>/devices`；daemon `ProjectRoot` 改用
  `devices/manifest` 标记。
