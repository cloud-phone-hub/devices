## 1. manifest 校验

```
$ python3 - <<'PY'
import xml.etree.ElementTree as ET, glob
for f in glob.glob('manifest/*.xml'):
    t = ET.parse(f)
    paths = [p.get('path') for p in t.getroot().iter('project')]
    bad = [p for p in paths if p and (p == 'engine' or p.startswith('core/') or p.startswith('engine/'))]
    print(f, 'projects=', len(paths), 'bad=', bad)
PY
```
