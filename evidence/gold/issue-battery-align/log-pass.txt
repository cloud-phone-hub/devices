== 6. 真机状态复位 ==
唤醒：svc power stayon true → mWakefulness=Awake；wm dismiss-keyguard 解锁。
熄屏：service call power 13 i64 <uptime_ms> i32 0 i32 0 → mWakefulness=Asleep。
（run-00025 在真机 Asleep 时下发返回「执行超时」；重启 app 前台后 run-00027 成功。）

== 9. 收尾复位 ==
真机：service call power 13 i64 <uptime_ms> i32 0 i32 0 → mWakefulness=Asleep。
云机：(root PTY) $ ip rule del pref 10500
      (root PTY) $ ip route del default via 100.64.155.2 dev ccmni2
      (root PTY) $ ip addr del 100.64.155.15/24 dev ccmni2
      → dumpsys connectivity 恢复 "Active default network: none"，agent 离线（预期）；
        health HAL 与 PowerCheckerService 30s 推送不受影响。
