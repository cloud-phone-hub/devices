#       mInitDoneSignal.await(10, SECONDS)   /* 超时 → 抛 IllegalStateException("... init timeout") */
#   PersistentDataBlockService$$ExternalSyntheticLambda0.run() 末尾才 signalInitDone()，

# ---- 3) 卡在第一步：打不开 ro.frp.pst ----
$ adb shell getprop ro.frp.pst
/dev/block/bootdevice/by-name/frp
# 官方 vendor build.prop 第 144 行即此值；本盘用机型静态树
#   vendor/etc/init/frp_symlink.rc（post-fs-data 建 by-name 目录 + symlink 到 vda3）
#   vendor/etc/ueventd.qcom.rc（/dev/block/vda3 0660 root system）
# 落到设备上：
lrwxrwxrwx root root   u:object_r:block_device:s0       /dev/block/bootdevice/by-name/frp -> /dev/block/vda3
brw-rw---- root system u:object_r:misc_block_device:s0  /dev/block/vda3

# ---- 4) 为什么拒 ----
# plat 只给 system_server 开了 frp_block_device，而本机节点的实际标签是
# misc_block_device（ueventd 按 /dev/block/vda 命名规则打标签）。
$ adb shell dmesg | grep -o 'avc:.*' | grep -E "system_server.*(blk_file|block_device)" | sort | uniq -c
# 与 m22 同源：m22 缺这条时同样卡在这里，修法可复用。
