# oriole：Google Pixel 6（lineage-21 / Android 14，官方固件 AP2A.240905.003.F1）

9 条机型条目。oriole 的打通线一共 #101~#108，其中**跨机型机制**已移入 `../common/`：
#102（三条内核树 `/mnt/vendorpatch` 口径统一）、#107（`/vendor` 重定向从内核补丁改成
外部模块 `cdh_redirect.ko`）、#108（五机型推广并修掉 08 的重复注入与缓存失效）。
本目录只留 oriole 自身的起机链：#101 zygote bootstrap 命名空间 → #103 vendor lift manifest
→ #104 LCD 密度 → #105 / #106 A14 显示栈自编。
2026-11-04 起这条线在新引擎流水线（`cdh device build`）与 `5.10` 内核上复测，又踩出三层并全部闭环：#149 基线缺「纯 64 位锁」
（官方 vendor build.prop 的 `ro.zygote=zygote64_32` 连坐杀 primary zygote）、#150 官方 `ro.frp.pst` 导致 `TestHarnessModeService`/`PersistentDataBlockService` `invalid checksum` 杀 `system_server` + `ro.hwui.use_vulkan=true` 导致 UI 进程 `!gpuCount` 崩溃、#155 `5.10/0002-hwsim-fake-wifi.patch` 沿用旧版 `netif_receive_skb(skb)` 在 `cdh-wifi-rx` kthread（BH 未关）中触发 `tcp_delack_timer` 单核自死锁（5.10 改用 `netif_rx_ni(skb)`，6.1/6.6 同步改用 `netif_rx(skb)`）。

## 备注

- **A14 基座口径：只用 lineage-21 自己的件**。A15 借来的 graphics 整套已撤（#105），
  显示栈三件改成自编（#106）；判断某个 vendor 件能不能用时，先看它属于哪一代，
  不要按「能加载」当判据。

  观感与帧证据只能走 VNC（`out/tmp/vncshot.py`）。
- 官方 Pixel 固件与 lineage-21 底座混用（`/product` 来自官方 `product_a.img`、`/vendor`
  来自 lineage），跨分区取件已被禁止，必须逐条在基线 `vendor.lifts` 里声明来源。
