# gold：Xiaomi Redmi Note 13 5G（MT6833）

本目录是这台机型的全部证据条目（50 条）。`gold` 是 global 变体
（`OS3.0.10.0.VNQCNXM`，清单 `devices/manifest/xiaomi/gold`）；编号 #8~#41 的早期条目来自
**同一台物理机**的 CN 变体 `note13-5G-15`（`OS3.0.9.0.VNQCNXM`，v1 设备侧路线）——
同机不同 ROM，按机型合并到本目录，正文里写 `note13-5G-15` 就是指这台机。

- 当前路线：lineage ext4 基座 + 自研 HAL 重编进 staging；v1「官方 EROFS vendor 原地污染 +
  显示栈换装」路线已废弃（其证据条目已移除，见 `../README.md` 的「已移除条目」表）。
- 主线里程碑：首启直达 launcher（#2）、launcher 渲染线程崩溃（#3）、音频全通（#11~#14）、
  ADB 三层打通（#15~#19）、蓝牙 HCI 集成（#20~#22）、真机对拍 22 功能点（#96~#100）、
  partner 预装应用与 vda 扩盘（#123）。

## 备注

- **ADB offline 分三层**：握手层（#15，adbd 不 fork、hvc2 的 ADBKEY1 被删）、网络层（#16，
  adbd 已监听但 socket 被 pioneer 域拒绝）、binder 传 fd 时的 inode 检查（#17）。三层都在
  `/dev/hvc*` 上，症状同为 `adb devices` 显示 offline，判据要按「adbd 有没有 fork」「socket
  建没建出来」两级分开取证。
- **仅跑 `--only patch` 不会更新 `out/device/<...>/patch.img`**，必须重跑 pack 或手动发布并
  核对 sha256，否则复现 #32（VINTF manifest 整份缺失）。
- **引擎路线与 gold-15 原厂路线是两条臂**（#5 做过 A/B）：guest 侧 `gfxinfo` + 宿主大帧计数
  双端采样，A 臂 composer 走 HIDL 2.4、B 臂走 AIDL `hwc3-service.drm`，帧节奏无可测差异；
  引用 gold 的实测数据前先确认是哪条臂的镜像。
- **16 条只有 `solution.md`**（#8、#9、#13、#14、#18、#19、#23、#24、#25、#26、#28、#29、
  #30、#31、#34、#36）：早期未单独留日志，属历史欠账，不补造。另有两条只留单份日志——
