# x6876：Infinix GT 30 / X6876（`infinix/Infinix-X6876` / `mt6878` / GRF vendor=14, system=16）

2 条机型条目：#273 记录 `infinix/Infinix-X6876` 在借助通用 `IComposerExt` AIDL 协议桩与 GRF `mapper/minigbm*` 标签恢复图形链（[../common/issue-mtk-a16-composer-ext-aidl-stub-and-prepare-fallback/solution.md](../common/issue-mtk-a16-composer-ext-aidl-stub-and-prepare-fallback/solution.md)）后，定位并消除官方 `/system/etc/init/hw/init.rc:1232-1248` 三道传音防破解校验钩子（`Trigger_Rpmb`、`Trigger_P7`、`Trigger_keyfilesvfy`）被官方 `/odm/etc/build.prop` 跨层置 `1` 触发 `reboot,recovery` 的问题；#345 记录全栈打通 Wi-Fi 5GHz、蓝牙（禁用 LE Audio 消除断言崩溃）、NFC（独立 `odm:/etc/vconfig/NFC` 回填）、相机（`ITZService` AIDL 桩、V4L2 权限与 `CDCM_PAUSE` 休眠）、Radio（双 PDN `ccmni0` IMS + `ccmni1` 真外网）并注册内核 `/proc/ged` 节点与 `allowx` 策略根治渲染热路径日志风暴与桌面卡顿。
