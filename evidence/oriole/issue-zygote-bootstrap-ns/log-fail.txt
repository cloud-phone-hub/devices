## 结论
两次落点都活不过 6 s：
- /mnt/patch：vold 的 VolumeManager::start() 把载体当 stale mount，131 次
  "Found map ... referencing /mnt/patch/..." 后按 /proc/<pid>/maps 杀进程，
  首个被杀的是 vndservicemanager；它的 rc 里 onrestart class_restart main
  立刻把 zygote 拉起来（5.8 s，远早于 APEX 就绪 22 s），zygote 被永久钉在
  bootstrap 挂载命名空间 → CANNOT LINK ... libnativeloader.so not found。
- /mnt/vendor/patch：3924 条 avc denied { search } for name="vendor"
  tcontext=u:object_r:mnt_vendor_file:s0，zygote/vndservicemanager/hwservicemanager
  等全域命中；vndservicemanager 1.324 s exit 1 → class_restart main → zygote 1.33 s
  起、1.669 s exit 1。
