# xplore-x1：Blackview XPLORE X1（`blackview/XPLORE_X1` / Doke OS 5 / MT6877 / Android 15）

3 条机型条目：#296 记录 `blackview/XPLORE_X1`（`15-AP3A.240905.015.A2-20251126`，`lineage-22.2` + `kernel 6.6`）因 `/system/app/OdmFactory` 在 `BOOT_COMPLETED` 拉起 `AtCommandService` 触发 `com.android.phone` 空指针闪退、因缺少 `vendor.trustkernel.{keybox.deployed,rkp.uploaded}=true` 与对应 `vendor_init` SELinux 授权在状态栏右上角常驻 `Not Write Google Key / Not Write RKP` 红字水印、及漏配 `android.hardware.drm` / `android.hardware.neuralnetworks` 导致 `rkpdapp` 狂刷 71,496 条失败日志；#346 记录修复桌面 `1080x2460` 动态壁纸半屏荧光绿与 `y=1230` 断层、剥除顶层 `media_codecs.xml` 悬空 `Include`、合并原厂 21 个 `c2.mtk.*` 与 `4096x4096` `c2.v4l2.*` 编解码能力并修正 `media_config.xml` 优先级，打通桌面壁纸硬解、竖屏 `1080x2460` `screenrecord` 60fps 硬编与原生相机 FHD `1920x1080` 硬编录像；#347 记录修复 `09_build_vendor` 无平台 CIL 分支提前返回漏生 19 类占位服务 SELinux `add` 授权致每次切应用同步阻塞 `5~30s`、切换 Vulkan 基座至 `pastel` 消除 Chromium `Chrome_InProcGpu` 在 macOS Mesa Venus 上的 `100% CPU` 自旋死循环，并置 `persist.vendor.em.dy.debug=1` 停用 `netdiag` 崩溃循环。
