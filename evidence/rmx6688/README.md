# rmx6688：realme GT7（真我 GT7 国行 / MediaTek `mt6991` 天玑 9400+ / ColorOS 15.0.2 Realme UI 6.0 / Android 15）

1 条机型条目：#194 记录 realme GT7（`realme/RMX6688`，基线 `15-AP3A.240617.008-20250825`，`lineage-22.2` + 登记借用 `lineage-22.1` `kernel 6.6`）从一阶段缺失逻辑分区 `InitFatalReboot`（引擎侧已归入 [../common/issue-vendor-boot-drop-missing-logical-partitions](../common/issue-vendor-boot-drop-missing-logical-partitions/solution.md) #193）、二阶段 SELinux 属性与 `engineer_vendor_shell` `setexeccon` 致命重启、FRP 软链与 `*-virtualhal` 崩溃连坐、`SurfaceFlinger` 无守卫等待 `IDisplayColorFeature/default` 引发 606s Watchdog 杀 `system_server`、`ICharger/default` 缺失致粘性广播 `notifycode=-1` 误触发 `com.oplus.battery` 全局 80% 充电上限弹窗，到蓝牙 LE Audio / `0xefd` 厂商命令超时 / `AccessoryFramework` 残留 BLE 广播 `Reactor::Unregister` `EBADF` 崩溃及 `OplusCamera` 后台崩溃的全链路根治与长稳零异常闭环。
