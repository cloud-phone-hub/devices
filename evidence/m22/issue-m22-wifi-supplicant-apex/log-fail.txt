# 现象: 设置里的 WiFi 开关打不开（打开又自动弹回），扫不到也连不上任何 AP

== 7) 对照：同一底包上的图形栈早就靠 2b 摊平救活了 ==
# 修完 SELinux 之后实例 44 能进桌面，正是因为 hwc3/allocator 走了 2b 摊平；

# wpa_supplicant 这类「认证栈」不在集合里 → 单独一路漏掉。
