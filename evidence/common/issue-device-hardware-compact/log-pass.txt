## 第 2 节：13 份 JSON 与备份语义等价

```console
$ python3 - <<'EOF'
import json,glob
ok=True
for p in sorted(glob.glob('manifest/*/*/device.json')):
    rel=p.replace('manifest/','')
    bak='out/tmp/devicejson-backup-hw-20261103/'+rel.replace('/','__')
    new=json.load(open(p,encoding='utf-8')); old=json.load(open(bak,encoding='utf-8'))
    same=new==old
    if not same: ok=False
    print('%-32s 与备份等价=%-5s hardware条目=%2d' % (rel,same,len(new.get('hardware') or [])))
print('ALL OK' if ok else 'PROBLEM')
```

`oriole` / `3a` 的 rc=1 是「该设备有多份基线清单，必须 `--manifest`」，与本次改动无关
（#137 已记为同一个坑）。补上参数后均 rc=0：
