# roms 迁到仓库根 #239 —— 迁移后验证记录（2026-11-15）

## 1. 目录迁移

```
$ mv engine/roms roms
$ ls engine
out
$ ls roms
devices  lineage
$ du -sh roms
293G	roms
```

说明：仓库根 `roms/` 此前已存在但为空，mv 后需把 `roms/roms/{devices,lineage}`
上提一层（本机已执行并清理 .DS_Store 残留）。

## 2. 代码改动

- `engine.RomsRoot()` = `<仓库根>/roms`；
- `engine.Init()` 的 `isEngineRoot` 不再要求 `roms/`，改为 `out/` + 父目录是
  `<仓库根>`（engine/ + devices/manifest）；
- `cluster` 的节点 RomsDir、`server/roms.go` 的固件扫描根、
  `manifestview` 的输入 roms 根、SSH 目录探测同步；
- `official.go` 的 `readMarker` 增加旧绝对路径兜底（同名 + 同大小 + kind），
  避免迁移触发全量重解包；
- `.gitignore`：根目录新增 `roms/`，engine/.gitignore 移除 `roms/`。
