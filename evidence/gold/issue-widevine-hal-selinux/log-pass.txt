## 6. 框架层端到端：MediaDrm 能枚举到 Widevine 工厂

用 app_process 跑探针（`out/tmp/wv/probe/DrmProbe.java`，d8 出 dex）：

```console
$ adb shell 'CLASSPATH=/data/local/tmp/drmprobe.dex app_process /system/bin DrmProbe'
widevine_supported=true
clearkey_supported=false
drm_failed=java.lang.IllegalArgumentException: application package name cannot be null
```

`isCryptoSchemeSupported` 由 framework → mediadrmserver → DrmHal 向
`IDrmFactory/widevine` 询问，返回 true 即证明「框架确实看到了该 HAL 工厂」。
最后一条是 shell 进程没有包名、`MediaDrm` 构造被拒（app_process 拿不到包名，
hidden API 也不允许反射带包名的构造器），与 HAL 无关；`clearkey=false`
是因为云机没有 clearkey HAL，本卡点未涉及。

## 7. 实例重启后复验（2026-10-28 04:11 起）

为清掉宿主双重网关遗留的僵死 TCP 流（见 `../issue-daemon-backend-reap/`），
实例 5 停机后用修复版 daemon 重启（PID 15106），开机完成后复验：

```console
$ adb shell 'su 0 sh -c "getprop init.svc.vendor.drm-widevine-hal"'
running
$ adb shell "service list | grep IDrmFactory/widevine"
42	android.hardware.drm.IDrmFactory/widevine: [android.hardware.drm.IDrmFactory]
$ adb shell "ps -A | grep android.hardware.drm-service.widevine"
media          946     1   10884172   7032 0                   0 S android.hardware.drm-service.widevine
$ adb shell 'dalvikvm -cp /data/local/tmp/wvprobe.dex DrmProbe'
widevine_supported=true
clearkey_supported=true
drm_failed=java.lang.IllegalArgumentException: application package name cannot be null
$ grep -c 'scontext=u:r:hal_drm_widevine' out/core/daemon/runtime/gold_cn_OS3.0.10.0.VNQCNXM/5/qemu.log
0
```

说明：

- `init.svc.*` 属性以 shell uid（2000）读不到（本镜像的属性读策略），
  用 `su 0` 读取为 `running`；
- 本次开机的串口日志（`qemu.log`）同样记录到 init 启动该服务与 servicemanager
  的域判定：
  `qemu.log:2819 init: starting service 'vendor.drm-widevine-hal'...`、
  `qemu.log:2850 servicemanager: Caller(pid=551,uid=1013,sid=u:r:hal_drm_widevine:s0)
  Found android.hardware.drm.IDrmFactory/widevine in device VINTF manifest.`
  （串口行里的 pid 是 init 启动瞬间的编号；当前 `ps` 显示的是同一 APEX 二进制的
  现存活进程 946，`/proc/946/cmdline` 指向
  `/apex/com.google.android.widevine/bin/hw/android.hardware.drm-service.widevine`）；
- 本次 `clearkey_supported=true`（clearkey HAL 进程 859 已起），与 §6 当时
  未起来的状态不同，不影响 Widevine 结论；
- `drm_failed` 仍是 shell 无包名，属探针限制。
