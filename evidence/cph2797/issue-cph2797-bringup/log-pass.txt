# 原因（时序证据）：
ro.boottime.servicemanager   = 1.117 s   ← VINTF 数据库由 servicemanager 持有

# 必须在 init 的 post-fs-data（4.8 s，早于 class core 启动的 23 s）里做才有效。

## 验证 5：patch.img 的内核重定向白名单不含 /odm/etc/vintf（排除改内核以外的通路）
# engine/kernels/lineage-22-6.6/fs/namei.c:189-219 规则表：/vendor/{etc,bin,lib,lib64}、
