## 4. 重定向矩阵：socket 是触发点

$ adb shell "cmd audio ...; echo rc=$?"                                   -> rc=2  (0/1/2 全 socket)
$ adb shell "cmd audio ... 0</dev/null; echo rc=$?"                       -> rc=2
$ adb shell "cmd audio ... 1>/dev/null; echo rc=$?"                       -> rc=2
$ adb shell "cmd audio ... 2>/dev/null; echo rc=$?"                       -> rc=2
$ adb shell "cmd audio ... 0</dev/null 1>/dev/null 2>/dev/null; echo rc=$?" -> rc=0   <== 全换掉就成功
$ adb shell -t "cmd audio ...; echo rc=$?"                                -> rc=0   <== pty 也成功
$ adb shell "dumpsys audio >/dev/null; echo rc=$?"                        -> rc=0   <== pipe 不受影响

# adb shell 下 0/1/2 的真实指向
$ adb shell 'ls -l /proc/self/fd/0 /proc/self/fd/1 /proc/self/fd/2'
lrwx------ 1 shell shell 64 /proc/self/fd/0 -> socket:[351357]
lrwx------ 1 shell shell 64 /proc/self/fd/1 -> socket:[351357]
lrwx------ 1 shell shell 64 /proc/self/fd/2 -> socket:[351359]

# 带 -t 时 0 是 pty
$ adb shell -t 'ls -l /proc/self/fd/0'
lrwx------ 1 shell shell 64 /proc/self/fd/0 -> /dev/pts/1
