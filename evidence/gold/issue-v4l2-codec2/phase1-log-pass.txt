# 实例：gold_OS3.0.10.0.VNQCNXM/34（2026-10-26 15:00:50 重启，全新内核会话）
# 镜像：patch.img sha256 a94930d30a16…（rebuild.sh 于 15:00 产出）

# 本轮修复（相对 log-fail.txt 的失败态）：
#   1) /vendor/etc/init/android.hardware.media.c2@1.2-service-v4l2-64.rc 整体注释
#      + /vendor/etc/vintf/manifest/android.hardware.media.c2@1.2-service-v4l2.xml
#      清空声明 + /vendor/etc/media_codecs_c2.xml 注释掉 3 条 c2.v4l2.*
#      （三处缺一不可：rc 只管 class_start，vintf 管 lazy HAL 按需拉起，

#      把 Watchdog 的 30s 硬超时放大到 300s
#   3) 机型层 sepolicy（manifest/xiaomi/gold/sepolicy/vendor_sepolicy.cil）补齐
#      mtk c2 / dolby c2 / radio HAL 的类型与授权，三者从崩溃循环转为 running

## 1. 属性：ro.hw_timeout_multiplier 从 build.prop 生效

sys.boot_completed=1
sys.init.updatable_crashing=[]

## 2. HAL 服务：三个此前 4 分钟崩 4 次的服务全部 running

media-c2-hal=running
dolby-c2-hal=running
