== 7) 一处易踩的坑：残留的 WifiConfigStore 会让连接假性失败 ==
# gold 首次 connect VirtWifi 失败，日志是
#   wpa_supplicant: assoc key_mgmt 0x0 network key_mgmt 0x4
#   ClientModeImpl: Network not found event received: network: "VirtWifi"
# 0x4=WPA-PSK 是上一轮实验留下的旧 network 配置（同一 SSID 两条，id 都 0）；
# `cmd wifi forget-network 0` 清掉后重连即成功。不是本问题的复发。
$ adb shell cmd wifi forget-network 0   → Forget successful
$ adb shell cmd wifi connect-network CDH-A open → 连接成功
