## 注释是错的来源

`engine/build/internal/manifest/manifest.go` 里 `Kernel()` 的口径说明（改前）：

    // 顶层 kernel 的口径是「抄 rom.vendor.kernel.uname-version 的主次」：云机跑的是
    // 厂商固件那颗内核，驱动/模块按它编，所以厂商线就是选核依据（gold：vendor
    // 6.6.89 + lineage-22.2 → lineage-22-6.6）。…与厂商线不一致则必须有借用登记。

gold 是「厂商线与底包同代」的特例，被写成了通则；最后一句还把借用登记的对象说错了——
`verifyKernelBase` 校验的是**编出来的 release 与底包 boot.img** 是否同代
（`02_build_kernel/plan.go:527~546`），与厂商 uname 无关。
