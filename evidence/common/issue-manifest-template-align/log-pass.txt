## 3. 相对链接

```bash
cd engine/manifest && python3 - <<'PY'
import glob,re,os
badlink=[]
for r in sorted(glob.glob('*/*/README.md')+['README.md','Template.md']):
    for m in re.finditer(r'\]\((\.{1,2}/[^)#]+)', open(r).read()):
        tgt=os.path.normpath(os.path.join(os.path.dirname(r), m.group(1)))
        if not os.path.exists(tgt): badlink.append(f'{r} -> {m.group(1)}')
print(f'[link] 坏链 = {len(badlink)}')
for b in badlink: print('   ',b)
PY
```

```text
[link] 坏链 = 1
    Template.md -> ../../../modules/cdh_redirect/README.md
```

唯一一条是 `Template.md` §3 骨架里的**示例链接**：它以 `manifest/<vendor>/<device>/` 为基准写，
抄进机型目录后正好指向 `engine/modules/cdh_redirect/README.md`；留在 `Template.md` 位置点开
必然 404。已在 §3 前言写明这条基准，故不算坏链。

机型 README 与 `manifest/README.md` 的坏链 **0**（本轮修掉的 3 条：
`nothing/3a` 的 `../flyme/m22/README.md` → `../../flyme/m22/README.md`、
`xiaomi/gold` 的 `../Template.md` / `../README.md` → `../../…`）。
