# cph2797：OPPO Find X9（ColorOS 16.0.8.301_EX01 / MediaTek `mt6993` / Android 16）

9 条，按 m22 / gold 范式接入 11 阶段流水线后逐卡点推进：#76 清单对齐与 07/08~11 全链构建
→ #77 首轮起机（图形 + 音频 VINTF）→ #78 SoundTrigger 空 HAL → #79 指纹扩展对空传感器表
零容错 → #80 power.stats 抢注同名 AIDL → #81 contexthub 声明旷缺 → #82 ColorOS 分辨率档位
→ #153 FRP 承载块设备缺失（本轮新引擎流水线首跑，system_server phase 500 崩溃循环）
→ #165 起机全链路收敛（VINTF 裁剪、MTK PowerHAL 锁、NFC 崩溃回环、ODM Telephony/IR 遮蔽与触控适配）。

条目按其修复顺序排列（#76~#82 连续；#153 是本轮补的，编号按全局递增取，见
[../README.md](../README.md) 的「编号规则」）；正文里的「上游条目：#N」表示上一处卡点。
整条链的形态一致：
ColorOS 的框架侧实现对「声明了但没有实现」的 HAL 零容错，system_server 一律 65 s 被
Watchdog 判死或直接自杀。本轮首跑另有两处**引擎级**卡点（属性重复键收口、odm 属性件取件目录
跨分区撞车），结论对所有机型成立，记在 [../common/README.md](../common/README.md) 的 #152 / #154。
