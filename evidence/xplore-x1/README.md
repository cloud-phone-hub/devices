# xplore-x1：Blackview XPLORE X1（`blackview/XPLORE_X1` / Doke OS 5 / MT6877 / Android 15）

2 条机型条目：#296 记录 `blackview/XPLORE_X1`（`15-AP3A.240905.015.A2-20251126`，`lineage-22.2` + `kernel 6.6`）因 `/system/app/OdmFactory` 在 `BOOT_COMPLETED` 拉起 `AtCommandService` 触发 `com.android.phone` 空指针闪退、因缺少 `vendor.trustkernel.{keybox.deployed,rkp.uploaded}=true` 与对应 `vendor_init` SELinux 授权在状态栏右上角常驻 `Not Write Google Key / Not Write RKP` 红字水印、及漏配 `android.hardware.drm` / `android.hardware.neuralnetworks` 导致 `rkpdapp` 狂刷 71,496 条失败日志；#346 记录修复桌面 `1080x2460` 动态壁纸半屏荧光绿与 `y=1230` 断层、剥除顶层 `media_codecs.xml` 悬空 `Include`、合并原厂 21 个 `c2.mtk.*` 与 `4096x4096` `c2.v4l2.*` 编解码能力并修正 `media_config.xml` 优先级，打通桌面壁纸硬解、竖屏 `1080x2460` `screenrecord` 60fps 硬编与原生相机 FHD `1920x1080` 硬编录像。
