2) 07_build_vendor：usr 层写了 2 个文件，装配树里却不存在
================================================================
07 日志摘录：
    机型静态树: 写入 20，已存在同内容 0
    机型 usr: 写入 2，已存在同内容 0
    ...
[ok] 已完成

但产物树没有 usr：
$ ls engine/out/devices/xiaomi/gold/OS3.0.10.0.VNQCNXM/vendor/usr/idc/
ls: .../vendor/usr/idc/: No such file or directory
$ ls engine/out/devices/xiaomi/gold/OS3.0.10.0.VNQCNXM/vendor/usr/keylayout/
ls: .../vendor/usr/keylayout/: No such file or directory

原因：overlayLayer{src: StaticTree/usr} 没设 base="usr"，登记键是 idc/…、
keylayout/…；pruneVendorDir 只放行 bin/etc/lib/lib64/firmware_mnt 与根级文件，
顶层 idc、keylayout 被当垃圾删除。日志统计发生在 prune 之前，因此仍报「写入 2」。
