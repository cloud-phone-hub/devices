# 通过现场：实例 16（全新 userdata，首开机 rc 自动钉分辨率档位 = 1）

# 日志全量：同目录 qemu.log；以下命令输出取自 guest root shell

# 1）置备脚本已跑完，并把档位写成 1（出厂默认是 2）
$ getprop init.svc.auto_provision

$ settings get secure oplus_customize_screen_resolution_adjust

# 2）整机尺寸回到原生，且没有 override
$ getprop sys.boot_completed

$ wm size

$ dumpsys display | grep -m1 mActiveModeId

# 3）DRM 真正切到了 preferred 模式（不是上层 override）
$ mount -t debugfs none /sys/kernel/debug

# 4）焦点回到 launcher
$ input keyevent 3
$ dumpsys window | grep -m1 mCurrentFocus
