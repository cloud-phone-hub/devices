## D. 宿主 Vulkan 探针（out/tmp/vkprobe.py，2026-10-26）

同一 ICD 内容，仅 is_portability_driver 不同：

$ VK_ICD_FILENAMES=out/tmp/MoltenVK_icd_port.json python3 out/tmp/vkprobe.py
vkCreateInstance -> -9        # VK_ERROR_INCOMPATIBLE_DRIVER

$ python3 out/tmp/vkprobe.py  # dist/lib/MoltenVK_icd.json（is_portability_driver=false）
vkCreateInstance -> 0
vkEnumeratePhysicalDevices -> 0 count = 1
device0: Apple M4 api=1.1.357

说明：Vulkan loader 的 portability 规则——ICD 声明 is_portability_driver=true 时，
未在 vkCreateInstance 启用 VK_KHR_portability_enumeration 的实例会被拒绝；
venus worker 不启用该位，故必须在 ICD 侧声明为普通驱动。

## F. hwui 源码断言位置（AOSP android15-release，本地副本）

engine/out/tmp/vulkanmanager.cpp（libs/hwui/renderthread/VulkanManager.cpp，871 行）：
  199:    LOG_ALWAYS_FATAL_IF(err < 0);
  234:    constexpr auto kRequestedQueueCount = 2;
  238:    for (uint32_t i = 0; i < queueCount; i++) {
  239:        if (queueProps[i].queueFlags & VK_QUEUE_GRAPHICS_BIT) {
  240:            mGraphicsQueueIndex = i;
  241:            LOG_ALWAYS_FATAL_IF(queueProps[i].queueCount < kRequestedQueueCount);
  242:            break;
  243:        }
  244:    }

即：修复宿主 ICD 后，venus 必须给出 >=2 队列的 GRAPHICS family，否则 hwui 必然
abort；宿主渲染栈无法满足时，只能在 guest 侧关闭 hwui Vulkan 后端（本次做法，
GLES/virgl 正常），或修改系统 libhwui（侵入路线，未采用）。

## 复现材料（同目录）

- vkprobe.py：ctypes 调用 dist/lib/libvulkan.1.dylib，打印 vkCreateInstance 结果与设备数
- vkqueues.py：枚举 queue family 的 flags 与 queueCount
- MoltenVK_icd_portability.json：is_portability_driver=true 的 ICD（复现 -9 用）
