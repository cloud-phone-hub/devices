== 6) 记账核对 ==
async 空间总量        = 520192 B（mmap 半边）
当前已用              = 520192 - 273888 = 246304 B
每对数据量            = 92 + 436 = 528 B
450 对 × 528 B        = 237600 B（+ binder 元数据 ≈ 246304）✓
打满阈值              = 520192 / 528 ≈ 985 对 ≈ 1970 条

== 8) 决定性 A/B：自动亮度就是开关（~12:37–12:44）==

$ D=/sys/kernel/debug/binder/proc/769
$ grep -o 'elapsed [0-9]*ms' $D | awk '{print $2+0}' | sort -n | head -1     # 最小 = 最新
