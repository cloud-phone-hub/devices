== 5. 宿主侧同时刻的判据：guest 忙等而非等 IO ==
$ ps -p 21442 -o %cpu,stat        # 实例 13
493.5  RN
$ ps -p 35420 -o %cpu,stat        # 实例 14
394.7  RN
# RN = running，%CPU 接近满核（8 vCPU 480%+ / 4 vCPU 394%）→ 所有 vCPU 在 guest 内核空转
# 此时 adb shell 单条命令全部超时，但 adb devices 仍显示 device（adbd 进程没死，被锁挡住）
$ ls -l 15/qemu.log               # 日志停写；实例 15（修后）同一时段 6 s 写 50 KB

== 6. 代码位置：约定的违反点 ==
$ grep -n "netif_receive_skb(skb);" engine/kernels/patches/lineage-23-6.12/0002-hwsim-fake-wifi.patch
+	netif_receive_skb(skb);
# 该行在 cdh_rx_inject() 末尾，由 cdh-wifi-rx 内核线程调用（进程上下文，BH 未禁用）。
# 上游约定见 net/core/dev.c 的 netif_receive_skb() 注释「must be called with BH disabled」；
# include/net/sock.h 的 bh_lock_sock() 就是 spin_lock(&sk->sk_lock.slock)，不禁 BH。
