## 4. 禁写根冲突

`agent/cmd/cdha/main.go` 把 `<仓库根>/out` 整棵放进 `fsx.DenyWriteRoots`：

```go
topOutDir := filepath.Join(workspaceRoot, "out")
if filepath.Clean(topOutDir) != filepath.Clean(agentOutDir) {
    denyWriteRoots = append(denyWriteRoots, topOutDir)
}
```

产物根若改成 `out/agent`，写 store 时会命中这条禁写规则（`ErrForbiddenTarget`），
必须先给禁写根加例外子目录。
