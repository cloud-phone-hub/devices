## 5. 源码级判据

### 5.1 guest Mesa 25.3.3 `src/virtio/vulkan/vn_physical_device.c`

```c
/* 1099-1117：只有 renderer 宣告 KHR_external_semaphore_fd 才去问 host */
if (physical_dev->renderer_extensions.KHR_external_semaphore_fd) {
   ...
   vn_call_vkGetPhysicalDeviceExternalSemaphoreProperties(...);
   physical_dev->renderer_sync_fd.semaphore_exportable = ...
   physical_dev->renderer_sync_fd.semaphore_importable = ...
}

/* 1163-1165：ANDROID_native_buffer 需要 semaphore import + fence export */
if (physical_dev->renderer_sync_fd.semaphore_importable &&
    physical_dev->renderer_sync_fd.fence_exportable)
   exts->ANDROID_native_buffer = true;

/* 1175-1181：整套 WSI 只要 semaphore_importable */
if (physical_dev->renderer_sync_fd.semaphore_importable) {
   exts->KHR_incremental_present = true;
   exts->KHR_present_id = true;
   ...
   exts->KHR_swapchain = true;
   ...
}
```

### 5.2 venus 服务端 `/Volumes/work/cloud-droid-hub/third-party/virglrenderer/src/venus`

```c
/* vkr_common.c:17 静态表里确实写了 true（119-121 行） */
.KHR_external_fence_fd = true,
.KHR_external_memory_fd = true,
.KHR_external_semaphore_fd = true,

/* 但 vkr_common.c:241 vkr_extension_table_init() 是按 host 枚举结果置位 */
memset(table, 0, sizeof(*table));
for (uint32_t i = 0; i < count; i++) {
   const int32_t index = vn_info_extension_index(exts[i]);
   if (index >= 0)
      table->enabled[index] = true;
}
```

host 枚举（MoltenVK）里没有 `*_fd` → venus 不转告 guest → guest `semaphore_importable=false`
→ `KHR_swapchain` 永不出现。

### 5.3 队列要求（第二道闸）

`VulkanManager.cpp:234-245` `LOG_ALWAYS_FATAL_IF(queueProps[i].queueCount < kRequestedQueueCount)`，
`kRequestedQueueCount=2`；venus/MoltenVK 每 family 只有 1 队列（gold 实测，见
`../../gold/issue-boot-to-launcher-vulkan/log-fail.txt` 的 `vkqueues.py` 输出）。
