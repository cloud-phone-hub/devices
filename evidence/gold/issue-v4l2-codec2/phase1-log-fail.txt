## 3. 根因 A：three-layer 缺失，v4l2 / mtk c2 / dolby c2 / radio 都起不来

# 3.1 只加 disabled 拦不住：rc 里声明了 interface aidl，init 按 lazy HAL 语义按需拉起
#     （加了 disabled 后 init.svc.* 仍是 restarting，dmesg 里 "starting service" 继续出现）

# 3.2 整体注释 rc + 清空 vintf 声明后服务停住，但 tv4l2 的 codec 声明还留在
#     /vendor/etc/media_codecs_c2.xml（357/360/365 行），MediaCodecList 仍列出 c2.v4l2.*

grep -c "c2.v4l2" /vendor/etc/media_codecs_c2.xml
3
