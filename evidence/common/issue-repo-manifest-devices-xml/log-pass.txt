## 1. XML 解析与项目路径去重

```
$ python3 - <<'PY'
import glob, xml.etree.ElementTree as ET
paths = {}
for f in sorted(glob.glob('manifest/*.xml')):
    root = ET.parse(f).getroot()
    inc = [e.get('name') for e in root.findall('include')]
    projs = [(e.get('path'), e.get('name')) for e in root.findall('project')]
    print(f, '| include:', inc, '| projects:', len(projs))
    for p, n in projs:
        if p in paths:
            print('  重复路径!', p, '已见于', paths[p])
        paths[p] = f
print('项目总数(不含 include 展开):', len(paths))
print('devices 顶层项目:', [p for p in paths if p == 'devices'])
```

## 3. 嵌套 project 沙盒实测（repo 2.71）

manifest：

```xml
<project path="devices" name="devices" remote="local" revision="main" />
<project path="devices/kernels/5.10" name="kernel" remote="local" revision="main" />
```

父仓库 `.gitignore`：`kernels/`、`modules/kernelsu/source/`。

```
$ repo sync -j1 --no-clone-bundle
```

`repo status` / `git status` 均不显脏，repo 未拒绝嵌套声明。
