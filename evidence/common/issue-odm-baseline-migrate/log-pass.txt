## 5. 失败面与路径反证

缺 `odm_a.img` 的解包根上跑 cph2797 06（编号前那次）：

```
    基线 odm 属性: odm_a.img:/etc/build.prop（sets 3 项 / unsets 0 项）
==> [步骤 1] 基线 odm 属性件: out/roms/oppo/cph2797/16.0.8.301_EX01/super/odm_a.img:/etc/build.prop（sets 3 项 / unsets 0 项）
[warn] 厂商镜像不在位: out/roms/oppo/cph2797/16.0.8.301_EX01/super/odm_a.img
[err] 取不到 odm 属性件：镜像 out/roms/oppo/cph2797/16.0.8.301_EX01/super/odm_a.img 里没有 /etc/build.prop，机型静态树也没有 manifest/oppo/cph2797/odm/etc/build.prop（先跑 01_unpack，或核对清单 odm.img / odm.prop）
exit status 1
```

「按 AOSP 习惯猜 /etc/build.prop」的反证（把 `prop` 临时改回 `/etc/build.prop`）：

```
    厂商原件: out/roms/oppo/cph2797/16.0.8.301_EX01/super/unpack_vendor/etc/build.prop（4 行 / sha256 c968cfee899f）
    [prop] 追加 persist.oplus.bt.em.adb.tool=true
    [prop] 追加 persist.vendor.oplus.icc.module.enable=1
    [prop] 追加 ro.odm.product.cpu.abilist=arm64-v8a
    [prop] 追加 ro.odm.product.cpu.abilist32=
    [prop] 追加 ro.odm.product.cpu.abilist64=arm64-v8a
    abilist32="" abilist64=arm64-v8a sha256=9 行 / sha256 17d3eb7fc0bb
```

→ 产物只剩 9 行（144 行正文 → 4 行存根 + 5 条追加）。改回 `/build.prop` 后恢复 141 行 /
`cfc266f70d54`。所以 `prop` 的实测值必须写进基线 `odm.note`，不能靠惯例推。
